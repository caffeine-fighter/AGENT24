# Slides

발표 copy와 시간은 [`deck.md`](deck.md)에 고정되어 있습니다. 표지를 포함해 정확히
5장, 총 120초이며 첫 10초에 합성 피해 `2개 · ₩98,000`을 보여줍니다.

최종 PDF와 PPTX는 용량 및 변경 이력 관리를 위해 Git에 넣지 않습니다. 이 issue의
산출물은 `deck.md`의 확정 copy이며, 실제 제출 시 아래 네 값을 같은 PR 또는 제출
기록에 추가합니다.

```text
PDF URL: 제출 시 기록
PDF SHA-256: 제출 시 기록
PPTX URL: 제출 시 기록
PPTX SHA-256: 제출 시 기록
```

URL과 hash가 없으면 `deck.md` 작성 완료와 별개로 대회 제출은 완료되지 않은 상태다.
